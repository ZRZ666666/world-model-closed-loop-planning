# 视觉世界模型的闭环规划与计算效率优化

本项目基于 **Temporal Straightening for Latent Planning** 的预训练世界模型，研究如何通过改进规划与执行策略，提高 PushT 目标到达效率并减少重复计算。世界模型保持冻结，改动集中在目标时间设置、历史信息使用和计划复用。

## 方法

**到达期限与历史上下文。** 在 Temporal Straightening 的原生梯度规划器上，加入递减的剩余到达期限，使前几轮重规划指向同一到达时刻；同时使用最近三帧观测和已执行动作补充运动历史。目标时间处理与 LePlanner 的到达拖延分析相关，区别在于本实现直接修改运行时的动作优化目标，无需额外训练控制器。[Temporal Straightening](https://arxiv.org/abs/2603.12231v3) · [LePlanner](https://arxiv.org/abs/2609.13845v1)

**反馈式计划复用。** 参考 AdaReP 的反馈式重规划思路，比较最新观测与原计划预测的偏差。当相对误差较小时继续执行剩余计划，否则重新优化。本实现采用固定误差阈值与复用次数上限，在保留环境反馈的同时减少规划调用。[AdaReP](https://arxiv.org/abs/2606.23079v2)

## 结果

| 改进 | 对照配置 | 已观察到的变化 |
|---|---|---|
| 到达期限＋历史上下文 | 原生冻结规划 | 成功率 **88% → 92%**；平均交互 **38.7 → 31.7 步**，减少 **18.1%** |
| 加入反馈式计划复用 | 已含期限与历史的规划 | 成功数保持 **14/16**；重规划 **114 → 51 次**，减少 **55.3%**；平均记录耗时减少 **49.6%** |

第一项使用来自 20 条轨迹的 50 个开发窗口；第二项使用同一开发池中的 16 个窗口。交互代价将失败记为 100 步，计时包含诊断开销。结果反映本地对照中的改进，尚未证明优于 LePlanner 或 AdaReP。
