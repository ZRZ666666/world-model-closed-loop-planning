# 视觉世界模型闭环规划毕业设计

本仓库整理基于 **Temporal Straightening for Latent Planning** 的既有闭环规划实验：在冻结世界模型上，检验到达期限、真实历史上下文和按预测误差复用计划的效果。任务为 PushT 仿真中的目标到达。

**这是已有成果与历史源码归档，不是新的实验结果，也不是开箱即用的复现包。** 2026-10-14 的整理仅涉及阅读、复制、文档编写与文件校验，未运行实验、训练或原分析脚本。

## 已有主要结果

| 对照 | 范围 | 已观察到的变化 |
|---|---|---|
| 原生本地冻结配置 → 到达期限＋三帧历史 | 50个开发窗口，来自20条轨迹 | 100步成功44/50→46/50；平均封顶交互38.7→31.7，减少18.1% |
| 同上，25步辅助指标 | 同一批窗口 | 16/50→43/50；单独期限控制也达到43/50 |
| 到达期限＋历史 → 加入误差门控计划复用 | 同一开发池前16个窗口，来自11条轨迹，另批重跑 | 成功均14/16；重规划114→51；平均记录墙钟134.695→67.918秒 |

这些是已消费开发数据上的描述性结果，不是独立测试、跨任务泛化或SOTA。第一组18.1%指交互节省，不指程序加速；第二组计时包含统一诊断开销，不能外推为普遍两倍加速。50窗口与16窗口实验分开解释。

## 研究归属

直接模型基础为 [Temporal Straightening](https://arxiv.org/abs/2603.12231v3)。[LePlanner](https://arxiv.org/abs/2609.13845v1) 已讨论滚动规划中目标到达被不断推迟的问题；[AdaReP](https://arxiv.org/abs/2606.23079v2) 已研究自适应重规划。仓库不宣称首创到达期限、历史输入或事件触发控制，也未完成与这些方法的同预算直接比较。

仓库公开用于毕业设计交流与审阅。公开可见不等于为全部内容授予统一开源许可；第三方权利不变，具体来源与许可见 `docs/CODE_PROVENANCE.md`。
