基于视觉世界模型的
闭环规划与计算效率优化

在已有模型不再训练的条件下，让动作计划更及时地完成任务，并减少重复规划的计算开销。

一、已完成的工作与主要进步

目前已搭建并使用 PushT 闭环实验系统，完成到达期限、历史输入与计划复用的对照。直接基础是 Temporal Straightening for Latent Planning 的公开 visual8 世界模型。我们保留已经训练好的模型，主要修改其规划和执行方式。

PushT 是仿真推物体任务：控制推杆，把T形物块推到指定的位置和角度。模型预测动作后果，规划器选择动作，仿真环境执行，再读取反馈。这里报告的是仿真中的实际闭环执行，没有开展真实机器人实验。

二、具体做了哪些改动

保持最初的到达期限

原生滚动规划每次都看未来25步，目标可能被不断推迟。我们的实现使初始期限连续倒计时：执行5步后还剩20步，再执行5步后还剩15步；超过初始25步后恢复原生全时域目标。模型权重没有更新。

使用实际观察到的三帧历史

除了当前图像，还使用本次执行中5步前、10步前的图像及中间已执行动作。启动时按实际可用信息使用一帧或两帧。原有本体观测包含推杆速度，但没有额外提供物块真值速度或源轨迹前史。历史可能帮助理解运动，但这一机制解释还没有被单独证明。

预测可靠时复用原计划

如果预测误差相对于预计运动量足够小，就沿用缓存动作；否则重新优化。固定阈值是0.5，最多连续复用两次。系统仍然每5步读取反馈并检查是否成功，减少的是重复优化的次数。

三、效果有多大

对照一：期限与历史

与原生配置相比，组合方法多完成2个窗口，成功率提高4个百分点；失败按100步计算时，平均交互减少7步，约18.1%。没有新增100步失败，但2个窗口的完成步数有所增加，并非每个任务都受益。

25步是辅助指标。目标恰由25步源动作构造；单独期限控制也达到43/50，因此不能把全部短预算收益归给历史。各臂每次规划均为5个时间单元、每单元5步，动作优化100次。成功判据为推杆与物块位置拼接的四维联合误差小于20像素且角度误差小于π/9，每5步检查。

18.1%是交互节省，不是运行加速。历史输入增加了编码计算；组合记录墙钟84.01秒，历史原生基线72.49秒，且不是同一时刻负载下的计时。

这组同批串行对照说明，部分已经算好的计划可以继续使用，在保持该批成功数的同时节省规划计算。计时包含统一监测与诊断开销，不能推广为所有部署条件下的两倍加速；它也不能与前一组50窗口数据合并解释。

完整数据还包含残差学习及组合对照，均未进一步提高100步成功数。因此不把神经网络残差训练作为已验证的主要收益。失败与退化结果均保留在归档中。

四、与已有研究的关系和毕业设计价值

相对于 Temporal Straightening 的本地原生配置，我们完成了期限与历史控制的实现和对照，观察到上述成功率和交互改善。该结果不是直接改写论文作者原表，也不是对 DINO-WM 或 JEPA-WMs 模型的改进实测。

LePlanner 已讨论滚动规划不断推迟到达的问题，AdaReP 已研究自适应重规划。因此，本课题不宣称首次提出期限控制或计划复用，也没有同预算证据表明超过这两篇论文。

目前较扎实的价值是完整工程实现、明确对照、同时评价任务效果与计算成本，以及可追溯的实验材料。50个窗口存在轨迹依赖，16个窗口也已经参与开发；尚缺独立目标、多随机种子和跨任务验证，不能称为SOTA或普遍泛化结论。

五、下一步建议

  1. 围绕这条主线完成方法、系统和实验章节，明确所继承的模型与已有控制思想。
  2. 经导师确定范围后锁定当前配置，再用未参与开发的目标检验收益。
  3. 增加固定频率重规划对照，判断误差门控是否优于简单少算几次；改变目标构造长度，检验期限收益的适用范围。
  4. 若需要扩展，可探索根据实际进展调整到达期限；目前只是后续方向，不属于已取得成果。
