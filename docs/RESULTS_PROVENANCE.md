# 结果来源

本仓库提供到达期限与历史上下文对照，以及反馈式计划复用对照的保存结果。文件级来源路径、原始摘要与公开副本摘要见[结果来源清单](../results/source_manifest.json)。

| 对照 | 数据范围 | 已保存内容 |
|---|---|---|
| 到达期限与历史上下文 | 50 个开发窗口、20 条轨迹 | 全部配置的逐案例表、配对表、因子对照、失败记录与汇总 |
| 计划复用及附加消融 | 同一开发池的 16 个窗口、11 条轨迹 | 全部配置的逐案例表、配对表、汇总与既有核查记录 |

公开结果只对原研究目录和用户目录进行路径替换，保留数值、任务标识、轨迹分组与成功失败记录。脱敏副本的文件摘要可能不同于原件；清单分别列出二者，内嵌历史摘要仍指向原始文件。

文档整理未重新运行模型、仿真或结果分析脚本。保存表格可用于核对报告数值，但不代替完整输入、预测和执行轨迹。已有审计属于当时执行的记录，文件摘要本身不证明研究结论。
